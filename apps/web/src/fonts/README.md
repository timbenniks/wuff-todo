# DM Sans

Upright and italic variable fonts from the Google Fonts DM Sans distribution, downloaded October 17, 2026:

- https://github.com/google/fonts/blob/main/ofl/dmsans/DMSans%5Bopsz%2Cwght%5D.ttf
- https://github.com/google/fonts/blob/main/ofl/dmsans/DMSans-Italic%5Bopsz%2Cwght%5D.ttf

Files are unmodified, renamed locally for stable paths. See OFL.txt for the SIL Open Font License and copyright notices. Next.js self-hosts these via next/font/local; scripts/build-mcp.mjs embeds the same files in the standalone MCP App. No runtime font CDN or additional CSP resource domain is required. Keep both delivery paths on the same files when updating.
