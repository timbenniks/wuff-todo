# Retired native documentation: tauri-live

Native apps and Tauri were retired on October 26, 2026 at Tim's explicit request.
Wuff Empire supports web, PWA and MCP. Do not build or publish native packages,
register native OAuth clients or add native module adapters.

See [the retirement decision and verification](native-retirement.md). Earlier
implementation evidence remains in Git history before this retirement; it is
not an active development or distribution guide. Published native test releases
and retained native Actions artifacts were removed, and their workflow disabled.
