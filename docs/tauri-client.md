## Initial foundation — WUFF-70

`apps/native` contains the React/Vite frontend and minimal Tauri 2 Rust shell. It uses the existing Waffles image, DM Sans font and `@wuff/design` palette. The frontend explicitly identifies itself as a development preview: login, API operations and live updates are follow-up tasks, not implemented behavior.

The shell has no native commands/plugins or granted capabilities. Production CSP allows local bundled assets and Tauri IPC only. Development CSP additionally permits the local Vite WebSocket and React development preamble. Authentication/network permissions will be added narrowly with WUFF-71/72. No production backend traffic is generated by this shell.

The Vite build rejects direct imports of server-only modules and the domain/database package source. Source assets temporarily come from the web workspace; WUFF-73 will establish shared UI/asset packaging. The copied app icon is derived from the existing Wuff 512px icon. Packaging is disabled until distribution configuration is verified.

## Commands

Read [development](development.md) first. Use the existing Node 22 and pnpm 10.33.3 workspace.

```sh
pnpm install --frozen-lockfile
pnpm dev:native:web
pnpm build:native:web
pnpm --filter @wuff/native tauri info
```

Web preview runs on `http://127.0.0.1:1420`. It proves React rendering, not native behavior. With a supported Rust toolchain installed:

```sh
pnpm dev:native
pnpm build:native
```

`build:native` requests a native binary without installer bundling. The reviewed `apps/native/src-tauri/Cargo.lock` is committed; keep it aligned with the native manifests. `src-tauri/target` and generated platform projects are ignored.

## Platform prerequisites and gates

- macOS: supported Rust/Cargo and Apple build tools; full Xcode is needed for iOS development and its signing/simulators.
- Windows: Windows build host, supported Rust target, Microsoft C++ build tools and WebView2 prerequisites.
- iOS: macOS, full Xcode, required Rust targets, simulator/device setup and signing for device builds.
- Android: Android SDK/NDK/JDK, required Rust targets and an emulator/device.

Follow [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) for exact supported versions when provisioning each host. Generated mobile platform projects remain disposable output. Use the current Tauri config and [platform matrix](tauri-platforms.md) for mobile build evidence and outstanding installed-device gates.

Earlier WUFF-70 checks lacked Rust/Cargo on the initial host. Subsequent macOS compilation and runtime evidence is recorded in [auth](tauri-auth.md) and [features](tauri-features.md). Verify toolchains on each host; full Xcode, physical-device acceptance and signing remain separate requirements.
